# Kindle F1 Dashboard 项目说明

## 1. 项目目标

目标是在 Kindle Paperwhite 1 上开发一个电子墨水 F1 信息展示工具。

最终效果：

- Kindle 可以显示 F1 相关信息
- 使用 E-Ink 屏幕低功耗展示
- 平时 Kindle 仍然可以正常阅读
- 通过 KUAL 菜单进入 F1 功能
- 执行完成后退出，不影响正常阅读
- 后续支持定时刷新

目标形态：

```
+-------------------------+
| F1 Dashboard            |
|                         |
| Next Race               |
| Singapore GP            |
|                         |
| Driver Standings        |
| Max Verstappen          |
|                         |
| Last Update: 10:30      |
+-------------------------+
```

# 10. KUAL 集成计划

> 经验(已实测验证):
> 本设备 KUAL(源自 KindleLauncher,版本 18b218e 20250103)通过
> `/mnt/us/extensions/<名称>/config.xml` **注册**扩展,只有 menu.json 不会显示。
> config.xml 中必须有 `<menus><menu type="json" dynamic="true">menu.json</menu></menus>`
> 声明菜单文件。新增/修改扩展后,KUAL 检测到变化会提示
> "new menu loaded please go to top"(新菜单在顶部,需向上滚动),
> 或重启 Kindle 使 `/var/tmp/KUAL.cache` 缓存失效。

最终效果：

```
KUAL

├── FileBrowser
│
├── USBNetwork
│
└── F1 Dashboard
      |
      ├── Refresh Now
      |
      ├── Start Service
      |
      └── Stop Service
```

# 10.5 屏保模式(Phase 4,规划中)

目标:设备休眠时,屏保显示 F1 面板;RTC 定时唤醒刷新后重新入睡,用户无感知。

## linkss 安装要点(参考 bookfere.com/post/311.html)

- 下载 kindle-linkss-0.25.N-rxxx.tar.xz
- **PW1 选 `Update_linkss_..._install_touch_pw.bin`**(另一个是 pw2_kt2_kv_pw3,不适用)
- 放入 /mnt/us/mrpackages,`;log mrpi` 安装,装完重启
- 装好后出现 /mnt/us/linkss/screensavers/,图片按 `bg_ss00.png` 序列命名
- 规格:KPW1/2 用 **758x1024 PNG**(必要时转 8 位灰度图;不能用改后缀的 jpg)
- 注意:与 Kindle 原生封面屏保功能冲突(本项目就是要替换它,可接受)
- 注意:usbnet 可能影响 linkss,屏保失效时重装 linkss 恢复

## 字体方案(已确认)

Pillow 渲染直接用系统字体(只读 rootfs,无需复制):

```
/usr/java/lib/fonts/Futura-Bold.ttf      # 标题
/usr/java/lib/fonts/Futura-Medium.ttf    # 正文
```

## 服务架构(最终版,已验证)

```
f1dash.py show       # 拉数据 → FBInk 直接显示(交互查看)
f1dash.py png        # 拉数据 → Pillow 渲染 → 写 linkss/screensavers/bg_ss00.png
f1dash.py service    # 守护进程:唤醒即刷新 + 清醒时每 30 分钟刷新
```

守护进程(每 3 秒轮询 powerd state):
- state -> active(唤醒):立即重新渲染 PNG
- 清醒期间每 30 分钟刷新一次
- 休眠时进程冻结,屏保显示最后一次生成的图(F1 数据变化不频繁,足够)

验证结果:
- ✅ 屏保渲染器把 758x1024 **等比缩放**到 600x800 屏幕,无偏移;
  内容画在画布中央 600x800 区域(偏移 79,112)(定位测试图验证)
- ✅ 入睡命令:`lipc-set-prop com.lab126.powerd powerButton 1`
- ✅ 唤醒检测 + 刷新(模拟入睡/唤醒循环验证,2 秒内完成)
- ❌ **RTC 定时唤醒不可行**(实测):sysfs wakealarm(rtc1)会触发但
  无法唤醒挂起中的内核;powerd 的 rtcWakeup 属性不接受外部设置
  (lipcErrNoSuchProperty)。因此放弃"休眠中定时刷新",改用唤醒即刷新
